Changes vs. the classic editor

Written for the Version History. Everything lives only in dev/level_editor_new.html - the shared css/level_editor/* and js/level_editor/* files are unchanged.

General

  • Smoother editor - animations that are off screen now stop, so the page no longer redraws all the time and lags, even on big maps
  • Collapsing and expanding waves is smooth again on big maps
  • Slimmer side margins around the whole editor (~20 % less)
  • Editor sections (Map, Map Settings, Towers, Waves, Abilities, Final JSON) have a warm brown gradient that darkens towards the bottom and a gold line along the top edge, instead of a flat brown box
  • Gold icons instead of emoji - panel tabs, Save Slot buttons and the Copy / Delete buttons on all cards
  • Section headings with gold icons, like Settings and Version History in the game (Map, Map Settings, Tower / Wave / Ability Editor, Final JSON)
  • Menu, Save Slots and Map Preview panels have a thin gold frame that runs around their tab too, plus a deeper shadow
  • Loading screen in the game's style - Cinzel title and a gold progress bar like the level progress
  • Confirm popups (Load Map, Overwrite / Delete Save Slot) now look like the game's popups - gold title with an icon, × in the corner, close with Esc or a click outside; the confirm button says what it does ("Load", "Overwrite", "Delete")
  • All selects look like the Background select in Settings, with a keyboard-friendly list; the ability select shows the ability icons
  • Every field gets a gold edge and a soft gold glow on hover and while you're editing it (inputs, selects, the − / + steppers, text areas)

Path checking

  • New live path checker instead of the "Validate Map Paths" button - checks the map (missing Start / End, a Start with no road to any End) and every enemy group's path (wrong format like "S1E", a Start / End that isn't on the map like "S1E6", no road between them)
  • Path errors stay above the Menu until they're fixed; the editor's step-by-step status messages are gone
  • Cross paths like S3E2 are valid, the same as in the game

Final JSON

  • Brown text area like the other inputs, monospace font, gold border while typing and a gold scrollbar
  • "Format & Copy JSON" moved to the left and shows "Copied!" for 2 s, "Export Map" stays on the right
  • Fixed: "Share Map" could stay stuck on "Copied!" after a quick double click

Save Slots

  • Slots look like cards - slot number in a dark socket, map name in gold, empty slots with a gold "+"
  • Wider panel with more room for the map name and bigger Save / Delete icons

Map

  • The tile picker now lies inside the map along its bottom edge, on a see-through dark strip; the selected tile is on the left, split off by a gold line and labelled "Selected"
  • The map can be panned a bit lower, so its bottom rows never stay hidden under the tile strip
  • A loaded or pasted map always opens centered
  • Tile search and filters (Terrains / Paths / Map Objects) are in one row right below the map; group names are gold
  • New Brush row - brush size, Square / Diamond / Circle and the X / Y position of the cursor in one line
  • Width / Height got − / + buttons
  • Map Style and Graphics moved into the Menu
  • The editor has its own graphics setting, separate from the game's Settings - changing one never changes the other
  • The editor starts on High graphics; Graphics Low / High always switches every object together (trees, portals, enemies, towers, water, terrain, roads, mountains, abilities and map objects - map objects used to stay on High) and the editor remembers your choice
  • Map Preview moved to the top-left corner
  • "Drawing is disabled for Start and End" moved into the tile search's "i" tooltip
  • The tile picker shows every tile as it really looks on the map, drawn by the game itself and following Graphics Low / High, with its name underneath; the "Selected" tile too
  • The tile legend ("i") shows "Can build towers" / "Can't build towers" in gold
  • The Map and Map Settings parts sit right on the section background (no extra dark boxes); the tile search field is brown like every other input

Menu

  • Test Map, Share Map and Help buttons in the Main Menu style (rounded, 3D edge, gold glow on hover)
  • The active tab (Map, Map Settings, Towers, Waves, Abilities) is gold, like in the Main Menu

Map Settings

  • Gold icons and centered headings for Title, Description, Starting Coins and Starting Lifes
  • Difficulty suggests ⭐ to ⭐⭐⭐⭐⭐, but you can still type your own value
  • Extra Life is an Off / On switch like Show FPS in Settings; when Off, Price Progression slides away
  • More space around the Price Progression row

Towers

  • Live preview of the tower's shop card next to its fields - exactly like the shop in the game, updates while you type and follows Graphics Low / High
  • Compact tower card - Color next to Name, stats in two rows; DPS moved from the header into the preview
  • Tower cards have a framed look with a soft gold edge and a lighter top, like the cards in the game
  • Drag, Copy and Delete buttons in card headers are the same size and in one line

Abilities

  • Ability cards have the background of their type over the whole card - lava, wind with arrows, falling coins, snow storm - like the ability cards in the game
  • Gold Rush - the Round Up checkbox is centered

Waves

  • Enemy groups of a wave sit side by side in one row that scrolls sideways; the mouse wheel over the row scrolls only the row, and the row keeps its position after every change
  • Compact group cards - "Group N" title, all 9 fields under each other, all fields the same height
  • A picture of the enemy above Type, drawn by the game itself - Golem, Fiery Eye, or both for Random (follows Graphics Low / High)
  • Hovering a Skin option shows that enemy next to the list
  • Dashed "+ Add Enemy Group" card at the end of each row; the row scrolls to a new or copied group
  • Waves are lighter at the top and darker at the bottom with a thin gold frame, like the tower cards
  • Enemy Types List in one sideways-scrolling row, its description inside the card
  • Enemy Types List, Enemy Shake Effects and Custom Enemy Damage each in their own card - lighter at the top, darker at the bottom, with a light gold frame; the Delete buttons line up with the fields
